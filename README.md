# CodSoft Java Development Internship - Task 2

## 🎓 Student Grade Calculator

A console-based Java program developed as part of the CodSoft Java Development Internship.

## 📌 Description

The Student Grade Calculator takes marks obtained in five subjects and calculates the total marks, average percentage, and corresponding grade.

The program also validates user input and accepts marks only between 0 and 100.

## ✨ Features

- Accepts marks for 5 subjects
- Marks validation (0-100)
- Calculates total marks
- Calculates average percentage
- Assigns grades automatically
- Handles invalid and non-numeric input
- Displays a clear final result

## 🛠️ Technologies Used

- Java
- Scanner
- Arrays
- Loops
- Conditional Statements
- Input Validation

## 📊 Grade Criteria

| Percentage | Grade |
|------------|-------|
| 90 - 100   | A+    |
| 80 - 89    | A     |
| 70 - 79    | B     |
| 60 - 69    | C     |
| 50 - 59    | D     |
| Below 50   | F     |

## ▶️ How to Run

1. Compile the Java program:
   
   `javac StudentGradeCalculator.java`

2. Run the program:
   
   `java StudentGradeCalculator`

3. Enter marks between 0 and 100 for each subject.
